# Security and responsible testing

anaAI is experimental hardware. There is **no validated safety function or released firmware**.

## Reports

For sensitive vulnerabilities, do not open a public issue containing exploitation details or credentials. No dedicated private security contact is configured yet. While this repository is private, open an issue with a non-sensitive summary to ask the maintainers for a secure reporting channel. Do not include vulnerability details, credentials or recordings until that channel is agreed. If GitHub private vulnerability reporting becomes available, prefer it.

## Privacy

Microphone recordings can contain voices and other private information. Collect with consent, store for the minimum necessary period, and strip identifying details before sharing. Never commit raw recordings by default.

## Hardware safety

No unattended automatic printer control in v0.1. Keep the monitor electrically isolated from printer control paths; use rated supplies and suitable strain relief. Treat a missed fault or false alert as an expected failure mode until validated.
